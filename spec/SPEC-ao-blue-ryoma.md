# Spec：越前龙马桌宠与澳网蓝主题

后续完成气泡的布局与关闭规则以 [SPEC-pet-message.md](SPEC-pet-message.md) 为准。

状态：2026-10-29 用户直接要求实施。覆盖早期深绿/奶油色主题和通用网球人物素材；浮窗优先、大窗口关闭独立、手动退出等规则继续遵循 `SPEC-floating-first.md`。

## 目标

- 桌宠换为《网球王子》越前龙马：白帽、深绿黑短发、琥珀色眼睛、青学蓝白红球服、左手持拍。生成持拍、击球、庆祝三张一致的透明适配素材。
- 主窗口、日程浮窗、编辑/候选弹窗、球场、提醒及桌宠气泡统一为澳网蓝主题：深浅双蓝、冰蓝底色、白色场线，网球黄仅作为球的辅助色。
- 保留布局尺寸、键盘与无障碍反馈、减少动态效果、解析和提醒规则；不引入在线视觉资源或新依赖。

## 实现与验收

1. 在 `tokens.css` 集中定义品牌蓝、文字/表面、控件、球场、状态与焦点色；移除组件对旧绿色主题变量的依赖。
2. 普通文字对背景的对比度达到 4.5:1；控件边界与焦点指示达到 3:1；状态继续同时使用文字与图案。
3. 新人物文件为 `ryoma-idle.png`、`ryoma-hit.png`、`ryoma-ace.png`，512×512 RGBA，每张小于 500KB，包含实际透明像素，主体和球拍完整可见。
4. 人物生成使用内置 imagegen，保留原图与完整提示词；旧人物资源保留，应用引用改为新文件。
5. 主窗口原生背景与 HTML theme-color 同步，避免启动时闪现旧奶油色。
6. 使用隔离演示数据检查主窗口 1180×780、860×620 与日程浮窗 360×560 的蓝色主题、文字对比及新人物显示。
7. 资源、人物动效和窗口生命周期回归通过；lint、typecheck、全量测试与 build 通过。完成后重启当前开发应用。

本轮只改视觉与素材，不改变单击仅打开浮窗、大窗口按需打开、关闭大窗口不退出应用的产品形态。
