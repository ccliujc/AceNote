# Spec：简洁日程浮窗

2026-10-30，用户提供“My Day”白底日程截图，要求小浮窗参考其样式，更简洁大气。本规格覆盖早期浮窗的深蓝输入卡、大号完成统计和底部实心主按钮，继续使用澳网蓝作为强调色。

## 设计与范围

- 保持原生浮窗 360×560px；白底、轻阴影、单层圆角面板，无重色卡片嵌套。
- 顶部为“我的一天”浅蓝胶囊、中文日期与小号无边框收起图标。
- 紧凑浅灰输入框，聚焦显示蓝色轮廓；右侧图标提交按钮保留“记录”无障碍名称。支持 Enter 提交、Shift+Enter 换行、Cmd/Ctrl+Enter 提交，输入法组合阶段不提交。
- 输入说明和字符数低调呈现；列表标题为“今天”与数量，完成数为辅助信息。
- 事项使用圆形状态图标、清晰标题、浅蓝时间标签；2026-10-30 按用户要求支持点击圆圈完成，详见 [SPEC-click-complete.md](SPEC-click-complete.md)。长标题允许换行，不显示多余的逐项分割线。
- 2026-10-30 用户要求进一步收紧列表：标题 13px / 20px 行高，时间标签 11px，事项上下内边距各 7px，标题与时间间距 3px，状态标记 16px；保持长标题换行与列表滚动。
- 底部“打开完整记录”变为文字入口，保留 Esc 收起和草稿保留提示。只保留已有功能，不新增没有实现的清单、设置、闹钟按钮或在线时间解析预览。
- 解析失败重试、原文转换、完成候选、请求锁、草稿与窗口生命周期保持现有规则；共享输入组件的默认主窗口样式和 Enter 换行习惯保持原样。

## 验证

1. 普通、长标题、空态、候选及失败反馈在 360×560px 可用，较窄工作区不横向溢出。
2. 提交快捷键、输入法保护、重复提交锁和共享主窗口输入交互通过回归。
3. lint、typecheck、测试与构建通过；隔离预览截图归档，重启开发应用。

交付与验证见 [todo-floating-minimal.md](../tasks/todo-floating-minimal.md)。
