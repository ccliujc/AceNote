# Spec: AceNote 桌面体验（desktop-experience）

最新视觉修订：越前龙马人物与澳网蓝主题以 [SPEC-ao-blue-ryoma.md](SPEC-ao-blue-ryoma.md) 为准；下文旧色值与旧人物说明保留为历史设计记录。

上游能力地图：`spec/CAPABILITY-MAP.md`

2026-10-29 用户修订：浮窗支持日程输入，角色替换为卡通网球人物；详见 `SPEC-floating-capture.md`。

2026-10-29 产品形态修订：浮窗作为主要入口，大窗口按需打开、关闭不退出应用；本规格的生命周期约定以 `SPEC-floating-first.md` 为准。

## 目标

把现有生命周期与提醒能力呈现为一致的网球主题桌面体验：独立悬浮桌宠、今日待办浮窗、带球场的每日记录主窗口，以及完成事项时的击球/Ace 动效。主窗口与桌宠旁的日程浮窗均支持文字输入，复用同一生命周期服务。

成功意味着：用户可从桌面桌宠直接记录或完成事项；主窗口能直观看到每日球场与列表；提醒在应用内可见；应用关闭行为明确，不残留后台进程；动画不阻塞数据和键盘操作。

## 已确认决策

- 使用**独立透明悬浮桌宠窗口 + 独立主窗口**。
- 桌宠使用**PNG 角色素材**，动效通过 CSS 变换与叠加层实现。
- **关闭大窗口仅收起该窗口**，桌宠和浮窗继续运行；显式退出才结束整个应用。
- 不添加托盘或开机启动；桌宠/浮窗提供持续可访问的入口，显式退出后不残留进程。
- 不申请系统通知权限，提醒继续以应用内形式呈现。

## 范围

### 包含

- 可拖动、始终置顶、透明背景的桌宠窗口。
- 桌宠位置持久化与多屏幕边界校正。
- 单击桌宠打开可输入日程的今日待办浮窗。
- 主窗口的每日网球场视觉、任务球和可访问列表。
- 未完成空心球、已完成实心球、已归档斜线球的视觉区分。
- 完成事项时的击球或 Ace 动效。
- 主窗口与桌宠同步刷新任务、提醒和完成事件。
- 所有窗口的加载、错误、空状态和退出行为。

### 不包含

- 托盘图标、开机启动、无可见入口的后台常驻、系统通知。
- 3D 物理、球体真实碰撞、复杂骨骼动画或视频素材。
- 语音输入、图片输入或拖放文件。
- 账号、云端同步和跨设备状态。
- 修改任务、提醒或解析业务规则。

## 技术栈

沿用 Electron、React、TypeScript、Vite、SQLite、Vitest。

- 多窗口由 Electron 主进程管理：`main`、`pet`、`quick-input`。
- `pet` 使用无边框、透明、置顶窗口；除角色区域外不阻塞桌面点击。
- PNG 资源通过 Vite 静态资源导入并随应用打包。
- 动画使用 CSS keyframes/transform，并支持 `prefers-reduced-motion`。
- 跨窗口同步通过最小、经 Zod 校验的 IPC 事件。
- 主窗口和今日待办浮窗共享同一套任务查询与事件契约，不复制业务规则。

## 窗口与交互

### 主窗口

- 启动不创建大窗口；仅在“打开完整记录”时创建。普通关闭拦截为收起，不关闭桌宠或浮窗。
- 布局包含：品牌与日期、球场视图、统一输入、每日列表、提醒中心。
- 球场视图与列表使用同一份当日任务数据；任一视图操作后两者同步。
- 窗口最小尺寸需保证 860×620 下操作项不重叠。
- 大窗口最小化或关闭后桌宠与浮窗仍可用；显式退出通过桌宠右键或系统退出命令。

### 桌宠窗口

- 无边框、透明、始终置顶、不可缩放，默认 220×220 逻辑像素。
- 启动时在最后保存位置出现；无保存位置时出现在当前主屏幕右下安全区域。
- 拖动仅移动桌宠窗口，位置保存到 Electron `userData` 下的 `pet-position.json`。
- 位置必须按当前显示器工作区校正；显示器移除后回退到主屏幕。
- PNG 角色之外的透明区域不得拦截桌面点击。
- 单击打开/聚焦日程浮窗；双击仍只打开浮窗，不触发大窗口。
- 右键菜单提供“打开完整记录”和“退出 AceNote”；本期不增加托盘。
- 不使用系统通知；提醒到达时播放一次轻微跳动并展示应用内对话气泡。

### 今日待办浮窗

- 宽约 360 像素、高约 560 像素（按屏幕工作区钳制）、无系统边框、置顶，紧贴桌宠左侧或右侧并钳制在屏幕内。
- 支持日程/完成指令输入，同时展示设备当前日期的待办，包含标题、状态、截止时间和当天完成数。
- 最多展示 7 项，超出显示剩余数量；提供与主窗口相同的记录、重试和候选确认；列表不提供字段编辑。
- 与主窗口共用同一任务查询与 `data:changed` 事件，不直接访问数据库。
- 点击“打开完整记录”按需创建/显示大窗口，浮窗保持显示。
- 浮窗失焦保持显示；仅手动收起。Esc/关闭按钮收起并保留会话草稿，候选状态下 Esc 先取消选择；提交期间阻止关闭。重开时重新定位到桌宠旁；数据变化后自动刷新。
- 今日无待办时显示空状态，不伪造任务。

### 应用退出

- 大窗口关闭不退出；真正退出前标记退出状态，再由 `before-quit` 停止调度器并关闭 SQLite。
- 桌宠右键“退出 AceNote”和系统退出命令使用同一路径；普通关闭大窗口不走该路径。
- 不增加托盘图标；真正退出后不残留窗口或后台进程。

## 视觉设计

### PNG 资源

首期随仓库提供以下透明 PNG，统一画布 512×512：

- `tennis-player-idle.png`：原创卡通网球人物，持拍准备姿态。
- `tennis-player-hit.png`：挥拍/击球姿态。
- `tennis-player-ace.png`：Ace 庆祝姿态。

资源要求：

- 透明背景、无文字、无投影依赖，主体留出 8% 安全边距。
- 在浅色与深色桌面上均可辨认。
- 单文件小于 500 KB；使用 2x 分辨率避免 Retina 模糊。
- 不引用远程图片或在线字体；应用离线可用（DeepSeek 解析除外）。

### 球场与任务球

- 主窗口球场使用奶油色底、深绿边线、球网和发球区线条。
- 任务球按记录顺序排布在球场内，使用确定性布局避免重叠。
- `open`：空心网球轮廓。
- `completed`：实心黄绿色网球，可带细网纹。
- `archived`：网球叠加斜线。
- 任务球是可选按钮，点击选中对应列表项并显示编辑入口；键盘用户可直接操作列表。
- 最多同时显示 24 个球；超出时显示“还有 N 项”并引导使用列表。
- 空球场显示轻量引导文案，不伪造任务。

### 动效

- 桌宠空闲：3 秒循环的 2–4 px 上下浮动。
- 提醒到达：单次轻微弹跳，不遮挡输入框。
- 任务完成：桌宠切换 `tennis-player-hit.png`，播放约 700ms 挥拍；Ace 状态追加一次金色光环/纸屑 CSS 层。
- 动效结束恢复 `tennis-player-idle.png`；同一时刻只播放一次，后续完成排队折叠为一次。
- 列表和统计数据先更新，动画异步播放，失败不影响任务状态。
- `prefers-reduced-motion: reduce` 时禁用位移、缩放和纸屑，仅显示静态状态图标。

## 跨窗口数据与事件

新增经 Zod 校验的主进程广播：

- `task:completed`：只含任务 ID 和标题，触发桌宠完成动效。
- 现有 `reminder:due`：主窗口与桌宠共享；桌宠显示气泡，主窗口显示提醒中心。
- 任务新增、编辑、完成、归档、恢复后广播 `data:changed`，主窗口和今日待办浮窗重新拉取数据。
- 事件只由主进程发出，渲染进程不能伪造任务事件；发送前校验 payload。

主进程窗口管理职责：

- 创建/聚焦/关闭三个窗口，处理 `ready-to-show` 和加载失败。
- `pet` 和 `quick-input` 启用上下文隔离、禁用 Node 集成、使用专用 preload。
- 不允许 `window.open` 或导航到外部 URL。
- 大窗口关闭仅收起自身；桌宠和浮窗不受影响。真正退出时允许所有窗口销毁。

## 代码风格

- 窗口尺寸、资源路径和事件名集中定义，不散落魔法字符串。
- 渲染进程不访问 Node、文件系统、数据库或密钥。
- 任务球布局使用纯函数，输入任务数组输出稳定坐标。
- 动画状态由明确枚举控制：`idle`、`reminder`、`hit`、`ace`。
- 所有异步提交有处理中和失败状态；UI 不使用乐观状态伪造完成。

```ts
type PetMood = 'idle' | 'reminder' | 'hit' | 'ace';

const petAssets: Record<PetMood, string> = {
  idle: petIdle,
  reminder: petIdle,
  hit: petHit,
  ace: petAce,
};
```

## 测试策略

- 窗口管理测试使用 Electron mock，覆盖浮窗优先启动、大窗口延迟创建、关闭独立、真实退出、位置校正和窗口 API 安全配置。
- 拖动位置测试覆盖保存、恢复、负坐标、显示器移除和缩放变化。
- 今日待办浮窗测试覆盖当天列表、状态、空状态、7 项上限、数据刷新、失焦保留与手动收起。
- 球场布局测试覆盖 0、1、24、25 个任务的稳定坐标、状态图案和键盘选择。
- 数据同步测试覆盖新增/完成/归档后广播与刷新，事件去重和非法 payload。
- 动画测试使用 fake timer，覆盖完成触发、排队折叠、恢复 idle 和 reduced motion。
- 资源检查测试断言三张 PNG 存在、透明、尺寸 512×512 且大小合规。
- 关键体验模块语句和分支覆盖率不低于 80%。
- Windows/macOS 窗口行为分别验证；未执行平台不得标记通过。

## 边界

### 总是做

- 保持浮窗优先、大窗口关闭独立；显式退出后释放所有窗口和进程，不增加托盘。
- 拖拽和位置恢复时钳制桌宠在可见工作区。
- 保证透明区域不阻塞桌面点击。
- 用同一生命周期服务处理所有窗口输入。
- 完成后再播放动效，动画失败不回滚任务。
- 支持键盘操作列表与减少动态效果设置。

### 先问再做

- 增加托盘、开机启动、后台常驻或系统通知。
- 引入新图片、视频、骨骼动画或远程字体资源。
- 修改窗口结构、浮窗优先入口或显式退出方式。
- 增加第三桌面窗口或改变安全 preload 边界。
- 修改球场最多 24 个球的限制或完成事件语义。

### 绝不做

- 在透明桌宠区域拦截整个桌面的点击。
- 在渲染进程直接读取数据库、文件系统或 DeepSeek 密钥。
- 在任务提交失败时播放成功动效或显示已完成状态。
- 允许拖动把桌宠永久放到不可见区域。
- 显式退出后继续在后台静默运行，或关闭大窗口时连带关闭浮窗。

## 成功标准

1. 应用启动仅创建桌宠，大窗口按需创建；单击/激活只打开浮窗；关闭大窗口不影响浮窗，显式退出才关闭所有窗口和进程。
2. 桌宠可拖动，重启后恢复位置，并在显示器变化时钳制到可见工作区。
3. 桌宠透明区域不阻挡桌面点击；单击/双击只打开日程浮窗，大窗口只通过明确入口打开。
4. 今日待办浮窗支持文字记录和完成指令，展示当天任务、状态和完成数，超出 7 项显示剩余数量，并随数据变化刷新。
5. 主窗口每日球场显示任务球和状态图案，列表提供等价键盘与编辑操作。
6. 25 个任务时球场最多显示 24 个球并展示剩余数量，不出现重叠或崩溃。
7. 完成事项后桌宠播放一次击球/Ace 动效，任务数据先更新；失败场景不播放成功动效。
8. 提醒到期时桌宠显示气泡，主窗口显示提醒中心；同一提醒不重复弹出。
9. 三张 PNG 资源存在、透明、尺寸和体积符合约定，应用除 DeepSeek 外不依赖网络资源。
10. 弱动态设置下不播放位移、缩放或纸屑，仍能识别任务完成状态。
11. 主窗口、桌宠和今日待办浮窗均启用上下文隔离、禁用 Node 集成且无外部导航。
12. 窗口、布局、事件、资源和动画测试通过；关键模块覆盖率不低于 80%。
