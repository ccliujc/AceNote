# Spec：完成提示气泡

2026-10-29，用户直接要求改进完成弹窗：缩小关闭按钮、无边框、15 秒后自动关闭、不遮挡人物。

- 气泡和关闭按钮均去掉边框，保留轻阴影、圆角与澳网蓝交互色；关闭图标 10px，点击区域 24×24px，支持键盘焦点。
- 人物维持 220×220px 的原有区域，上方额外预留 120px 提示空间；完整透明桌宠窗口为 220×340px，长文本限制在提示区内滚动，气泡不覆盖人物或庆祝动作。
- 完成与提醒消息均显示 15 秒，使用独立于动作的计时器；新消息（包括相同标题）重置计时，手动关闭及卸载清理旧计时器。
- 透明空白区域继续穿透鼠标；消息收起后释放提示区域，人物区域保持可交互。
- 持久化位置继续代表原人物区域左上角，扩展窗口时向上预留空间，避免已有人物位置无故上移；窗口/拖动边界使用扩展后的尺寸，日程浮窗仍与人物底部对齐。
- 不改变单击只打开日程浮窗、完整记录按需打开、关闭大窗口不退出的产品规则。

验证与截图见 [todo-pet-message.md](../tasks/todo-pet-message.md)。本规格覆盖旧文档中桌宠窗口固定 220×220px 和提示覆盖人物的布局描述。
