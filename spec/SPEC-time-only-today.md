# Spec：省略日期的明确时刻默认今天

2026-10-30，用户明确要求：日期省略时视为今天。覆盖 capture 早期“只有时刻、日期不明确则清空”的规则。

- 新建事项包含明确时刻、未提日期时，使用提交时设备 IANA 时区对应的当天日期。12 点为 12:00，五点半为 05:30，下午 2 点为 14:00。
- 今天已过的时刻仍保存为今天，不自动顺延明天，不补发过期提醒；浮窗显示“已过时间”。
- 日期和时刻都没提及时仍按原有记录日期保存，截止字段保持空，不凭空建立 09:00 提醒。
- 有明确日期、相对日期、模糊日期、重复/间隔或多个时刻时不应用“省略日期”兜底，继续由模型按明确表达解析或保留未知。
- 更新模型提示词，同时为单个常见中文/24 小时时刻增加确定性兜底；输出仍需通过原有严格 schema，不接受额外字段或非法值。
- 日期计算只使用请求接收时间和设备时区，不使用服务端运行日期；重试沿用原 intake 的接收时间。
- 保存后明确显示解析后的时间；应用内提醒仍只在应用运行时生效。无新增后台/系统通知、数据库字段或依赖。
- 不批量修改既有记录，不改原文、记录时间、手动编辑保护或完成指令。

验证：包含模型漏时间、跨 UTC 日期、已过时刻、显式明天、无时间、模糊/重复/多个时间、非法输出、实际提醒计划与一次触发、浮窗展示。运行 lint、typecheck、测试、覆盖率和构建并重启。
