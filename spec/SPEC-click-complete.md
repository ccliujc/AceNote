# Spec：点击圆圈完成日程

2026-10-30，用户要求点击小浮窗日程前的圆圈即可完成事项。本规格覆盖早期“状态标记只读”的约定，保留紧凑列表尺寸。

- 未完成事项的圆圈改为语义按钮，支持鼠标点击及 Enter/Space；视觉圆圈仍为 16px，点击区域 24×24px，不增加行高。
- 按事项 ID 和当前 revision 直接调用本地生命周期完成接口，不调用模型，也不新建 intake。因此未配置 DeepSeek 或离线时也可完成已有事项。
- 主进程校验 UUID / 非负整数 revision，沿用仓库的原子状态转换、完成时间与完成日期统计；旧版本、重复完成和归档事项的完成请求失败时不得产生副作用。
- 成功后取消原提醒、发送统一完成/数据更新事件，更新列表与完成数，并复用人物击球/庆祝及 15 秒完成消息。
- 请求中显示圆圈加载反馈并阻止重复提交及其他冲突操作；成功前不先把事项画成已完成。
- 手动完成保留输入草稿和未处理的输入反馈；失败保留状态、显示错误并重新加载最新事项。
- 已完成和已归档事项不可再次点击完成；误操作可在完整记录中使用已有“恢复”入口。
- 不修改原文、记录日期、提醒调度、窗口关闭或自然语言完成规则。

验证涵盖 ID 精确选择、无模型调用、提醒取消/事件一次、过期 revision、IPC 校验、预加载桥、点击/键盘、草稿保留、防重复及失败恢复，并完成静态检查、测试、构建和隔离预览。

交付记录见 [todo-click-complete.md](../tasks/todo-click-complete.md)。
