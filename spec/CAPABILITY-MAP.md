# 能力地图：AceNote

来源：`AceNote-需求说明书-v0.3.docx`（2026-10-25，需求草案）

2026-11-01：剩余功能、试用交付与后续账号能力的整理见 [下一阶段需求说明书](PRD-next-release.md)（F01 已交付，其余见各项状态）。当前可用行为继续以对应模块的现行规格与 README 为准。

## 当前假设

1. 当前项目由 Electron + React + TypeScript 桌面客户端和本机解析服务组成；腾讯云服务与云端存储为后续目标，当前运行不依赖云端部署。
2. 核心功能阶段采用本地单用户模式，无需注册或登录；SQLite 保存原文、识别字段、任务状态、每日记录和提醒配置。
3. DeepSeek API 仅由受控服务端调用，密钥不进入桌面客户端；账号接入前的访问限制在 `capture` 规格中明确。
4. `identity` 延后到核心功能验证之后，再接入账号、云端长期存储和既有本地数据的归属迁移。
5. 首期不做多设备实时同步；注册方式、提醒补发规则和归档恢复入口在对应模块规格阶段确认。

## 模块

| 模块 id              | 职责                                                                                                | 依赖                                                           |
| -------------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `capture`            | 本地快速文字提交、原文保存、DeepSeek 字段解析、识别结果查看与修改、离线重试                         | —                                                              |
| `task-lifecycle`     | 每日记录、任务状态、文字完成指令与歧义处理、完成时间、手动归档、完成统计                            | `capture`                                                      |
| `reminders`          | 本地截止时间计算、应用内提醒、提醒更新与取消；无具体时间时默认当地 09:00                            | `task-lifecycle`                                               |
| `desktop-experience` | 可拖动悬浮桌宠、日程输入与今日待办浮窗、每日列表、网球场与状态图案、击球或 Ace 动效、客户端生命周期 | `capture`, `task-lifecycle`, `reminders`                       |
| `identity`           | 账号注册、登录、退出、会话、云端数据归属与隔离，以及既有本地数据的账号绑定和迁移                    | `capture`, `task-lifecycle`, `reminders`, `desktop-experience` |

## 构建顺序

`capture` → `task-lifecycle` → `reminders` → `desktop-experience` → `identity`

`identity` 已有一份批准但暂缓的规格，不在本轮核心功能交付范围内。

输入恢复 F01 已实现，见 [验收记录](../tasks/verification-f01-input-recovery.md)。剩余模块补齐与试用交付的建议顺序为：提醒状态、重新识别及首次说明 → 应用内配置、安装包及原生验收 → `identity`。托管解析是独立可选方案，不与云端任务存储或实时同步混为一项。

## 跨模块契约

- `capture` 先以本地单用户模式输出包含原始文字、客户端记录时间、识别字段和解析状态的待办；模型不得生成或覆盖记录时间。
- `task-lifecycle` 向 `reminders` 提供完成、归档和截止时间变更事件，以取消或更新本地提醒。
- `desktop-experience` 负责呈现和交互，不替代字段校验或任务状态规则。
- `identity` 后续提供已认证用户身份、云端账号隔离和本地数据迁移，不得改变已验收的任务与提醒语义。
