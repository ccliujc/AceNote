## 实际接口与界面

在本地运行的解析服务中，用合成示例“12点钟提醒我吃饭”、接收时间 `2026-10-30T03:12:45.128Z` 和 `Asia/Shanghai` 调用 `/v1/parse`，实际返回：

```json
{
  "intent": "create",
  "task": {
    "title": "吃饭",
    "dueDate": "2026-10-30",
    "dueTime": "12:00",
    "contact": null
  }
}
```

此接口验证不写用户 SQLite。原有用户记录仅用于上一轮只读诊断；本轮没有批量补写或修改历史记录。

隔离浮窗预览使用真实 TodayPanelApp、真实时间补全模块和内存事件桥：提交示例后显示“已记下‘吃饭’，时间为今天 12:00”，下方显示 `12:00`；另一个已过 05:30 的演示事项显示“已过时间”。无真实数据库写入、无演示提醒调度。
