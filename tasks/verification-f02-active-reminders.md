## 原生隔离验收（V10）

环境：macOS 14.4.1、arm64、Electron 33.2.1，独立数据目录 `/tmp/acenote-f02-native/user-data`。预置 3 条合成任务：本次即将到期的 A、B，以及启动前已错过的 C。实际系统时钟到达 11:36 / 11:37，由生产调度器默认 15 秒轮询处理，没有直接伪造到期事件。

| 步骤                         | 真实结果                                                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 首次启动和实际到期           | 只创建 1 个人物窗口；C 标记为 missed，A / B 实际到期后活动数 2；未自动创建大窗口                                               |
| 气泡等待 15 秒后再开大窗口   | 气泡已收起，活动数仍为 2；点击人物先仅开浮窗，再明确打开完整记录，显示 2 张卡片                                                |
| 关闭 A                       | 卡片消失，B 仍保留；SQLite 中 A 的任务字段与关闭前完全相同                                                                     |
| A 改期并真实再次到期         | 经当前 editor preload / IPC 改为 11:37，计划数据库 ID 保持，实际再次到期得到不同 activationId，活动数回到 2                    |
| 旧引用关闭                   | 经真实 reminder IPC 提交 A 第一次触发的引用，新 A 和 B 均保留                                                                  |
| 关闭新的 A                   | 原生卡片点击后，正在显示 A 的气泡收起，B 保留；未按相同任务 ID 误关其他触发                                                    |
| 从浮窗圆圈完成 A             | 真实鼠标点击完成按钮，任务完成、完成数变为 1、人物显示完成提示；再次提交旧关闭引用仍不影响完成提示                             |
| 草稿、日期及独立关闭         | 主窗口与浮窗草稿、浏览日期保持；关闭大窗口只隐藏自身；收起浮窗后人物仍在，重新点击人物只复用浮窗并保留草稿                     |

## 存储、失败和回退边界

不增加迁移，数据库仍为版本 4。活动集合、去重身份及关闭结果仅在当前进程会话保存，退出清空；不把数据库历史 fired 等同于活动集合，也不更改原任务或计划 ID。每次实际触发另有 activationId，当前会话重复关闭幂等，旧会话报 CONCURRENT_EDIT。

计划写入仍是任务提交后的尽力同步；活动失效先使用已提交任务处理，查询和轮询再核对当前计划。抢占前重新核对任务截止字段，残留旧计划不能重新展示；单条失效数据不阻断其他有效计划。存储读取异常保留最后已知状态，恢复后可重试，不声称新增持久化事件队列或自动计划修复。

回退整包版本前正常退出，活动内存按正常重启规则清空，不降级 F01 数据表或删除历史行。旧版仍有原先查询与关闭不同步的局限。本次验证没有打开、备份或修改用户真实日程数据库。
